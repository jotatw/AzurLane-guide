# Sources

> Catálogo inicial das principais fontes utilizadas pela Azur Lane Knowledge Base.

## Objetivo

Este documento registra as fontes utilizadas para pesquisar, validar e contextualizar informações sobre Azur Lane.

Ele não determina sozinho a confiabilidade de uma informação. A avaliação das evidências segue as regras definidas em `METHODOLOGY.md`.

A lista é deliberadamente inicial. Novas fontes podem ser adicionadas conforme forem descobertas e avaliadas.

## Classificação

| Classe | Tipo | Uso principal |
|---|---|---|
| S1 | Oficial | Anúncios, alterações, eventos e informações publicadas pelos responsáveis pelo jogo. |
| S2 | Dados do jogo | Dados estruturados ou extraídos diretamente dos recursos do jogo. |
| S3 | Wiki / Database | Dados organizados e documentação comunitária. |
| S4 | Comunidade / Theorycraft | Discussões, experiências, análises e consenso de jogadores. |
| S5 | Guias / Criadores | Guias de progressão, estratégias e análises produzidas por jogadores ou criadores. |
| S6 | Ferramentas | Calculadoras, APIs, planners e outras ferramentas de apoio. |
| S7 | Histórico / Regional | Fontes úteis para versões antigas ou diferenças entre regiões. |

Fontes chinesas podem ser úteis para acompanhar conteúdo, mudanças e documentação que surgiram primeiro na versão chinesa.

## Arquivos Históricos

Fontes antigas, páginas arquivadas, vídeos e discussões históricas podem ser necessárias para reconstruir informações de eventos e sistemas que mudaram ou deixaram de existir.

**Regra:** conteúdo histórico deve ser identificado como histórico e não utilizado como descrição do estado atual sem confirmação.

---

# Avaliação das Fontes

Uma fonte não recebe automaticamente o mesmo nível de confiança apenas por pertencer a uma categoria.

A avaliação deve considerar:

- autoridade;
- atualidade;
- região e versão;
- origem dos dados;
- possibilidade de reprodução;
- consistência com outras fontes;
- existência de alterações posteriores;
- limitações conhecidas.

A classificação de confiança das conclusões está definida em `METHODOLOGY.md`.

---

# Uso de Conteúdo de Terceiros

Quando utilizarmos dados, código, imagens, documentação ou ferramentas de terceiros, devemos:

1. Identificar a origem.
2. Verificar a licença e as condições de uso.
3. Dar crédito quando exigido ou apropriado.
4. Manter o link para a fonte original quando possível.
5. Diferenciar claramente uma fonte consultada de material incorporado diretamente.

O projeto não deve copiar conteúdo de terceiros simplesmente porque ele está disponível publicamente.

---

# Manutenção

Uma fonte pode mudar de endereço, deixar de existir, ser abandonada ou perder relevância.

Quando isso ocorrer, a entrada deve ser revisada sem apagar automaticamente seu valor histórico.

Novas fontes devem ser adicionadas somente quando apresentarem utilidade real para a Knowledge Base.
